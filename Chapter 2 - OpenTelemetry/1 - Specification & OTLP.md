# Specification & OTLP

## Overview

In this part you'll learn about the OpenTelemetry specifications.
At the end of this part, you'll know in detail about the OpenTelemetry specification.
Especially, you'll know the OTLP protocol and other semantic conventions set by OpenTelemetry.

## Goals

- Learn about OTLP protocol and why it is needed
- Understand the inner workings of the OTLP
- Learn about Protobuf and gRPC, the building blocks OTLP is built on.

## Outcome

The outcome of this part should be a detailed markdown containing everything you have learned about OTLP and an **article explaining the OpenTelemetry specifications in depth**.

1. Explain what Protobuf is. What problem does it solve?
2. Explain what gRPC is and the need for it.
3. What is OTLP, and what does the OTLP specification define?
4. Why is OTLP needed?
5. Give 2 alternatives to OTLP and explain them in detail. Provide pros and cons for each of them.
6. Write a short paragraph explaining about the OpenTelemetry specification.
7. What are the semantic conventions specifications in OpenTelemetry? Why are they needed?
8. List some of the semantic conventions.
9. What is Open Agent Management Protocol? What is its use case?
