Q: stack vs heap
A: heap is a term related to the jvm, The heap is the run-time data area from which memory for all class instances and arrays is allocated.
   The heap is created on virtual machine start-up. Heap storage for objects is reclaimed by an automatic storage management system(gc).
   
   stack is a term related to the jvm, the stack is per thread memory storage that stores frames. it is used as a part of method invocation.
   it holds local variables and partial results,
   
Q: metaspace
A: off heap area used for classes metadata such as runtime representations of loaded classes, method definitions, vtables, and constant pools.

Q: Classloader mechnism
A: A class loader is an object that is responsible for loading classes. The class ClassLoader is an abstract class. Given the binary name of a class, 
   a class loader should attempt to locate or generate data that constitutes a definition for the class. 
   A typical strategy is to transform the name into a file name and then read a "class file" of that name from a file system.

Q: `map`
A: method that is applied to an element in some sort of data structure way and returns the element with the changes applied.

Q: `filter`
A: method that is applied to a data structure and returned all the elements that match a conditions.

Q: `reduce`
A: method that is applied to data structure and reducts elements using an associative accumulation function.

Q: `collect`
A: method that is applied to data structure and transform it into a given data structure.

Q: `flatMap`
A: method that is applied to a nested data structure and transform it into a flat data structure.

Q: `groupingBy`
A: method that Groups elements by a specific property and returns a Map<Key, List<Value>>.

Q: `partitioningBy`
A: method that spilits elements exaclty two groups based on a true/false condition. It always return a Map<Boolean, List<Value>>.

Q: `parallelStream()`
A: a method that returns a possibly parallel Stream with this collection as its source. It is allowable for this method to return a sequential stream.
