2. Name 2 different of instrumentation SDKs and explain the differences between them.
A: Two instumenation sdk's are:
	* OTEL sdk - The OpenTelemetry SDK provides a working implementation of the API,
		      Covers the "three pillars" of observability: Metrics, Traces, and Logs. It correlates them under a single, shared context.
		      Push-based. The application packaging up data inside the SDK aggressively pushes it out (via a protocol called OTLP) to an external collector or backend.  
		      It contains zero storage mechanisms. It acts purely as a factory and pipeline to ship your data elsewhere.
	* Prometheus sdk - The Prometheus SDK is part of an all-in-one metrics monitoring ecosystem originally built to track time-series data at scale.
			    Exclusively Metrics.
			    Pull-based (Scraping). The SDK spins up a mini HTTP server inside your application (usually at /metrics). It stores the data locally in memory until the central Prometheus Server periodically sweeps by and "scrapes" (pulls) it.
			    Built specifically to feed into the Prometheus Time-Series Database (TSDB), which handles querying via PromQL and alerting via Alertmanager.
